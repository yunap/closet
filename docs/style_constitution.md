# Style Constitution

This document is the SINGLE AUTHORITY for all style claims in the app.
Prompts must quote it or reference shared fragments derived from it. No model — including the
one drafting this — may add to it; additions come from Yuna or from feedback data, and carry
provenance.

**How to ratify:** check `[x]` to keep, strike or edit anything wrong, add what's missing.
Unchecked items get DELETED from prompts, not kept "just in case."

Provenance tags:
- **[doc]** — styling_session_context.md (note: that doc was co-written with a model and has
  itself produced at least one invented claim, so [doc] is evidence, not proof)
- **[chips]** — Yuna's actual feedback labels (Catalog drift, Teacher/librarian drift,
  Too soft, Catalog maturity drift, ...)
- **[session]** — established in later working sessions; lives only in chat memory until now
- **[confirm]** — plausible but unratified; default is CUT

## Layer 1 — Body & Comfort Contract (hard rules — apply to EVERY style, no exceptions)

These are mechanics, not aesthetics. They are the only "non-negotiables" in the system.

- [x] Nothing clings to the midsection — tops skim, never cling. [doc] [session]
- [x] No outfit engineering: no complicated tucks, no constant adjustment during wear.
      Simple tucking is fine. "When an outfit needs engineering to work, it's usually the
      wrong outfit." [doc, refined by Yuna 2026-06]
- [x] "Fitted" means "has some shape to it," NOT tight. [doc]
- [ ] Bust needs structure or addressed visual weight (fitted, dark, or fabric with built-in
      structure); loose unstructured tops through the bust read shapeless. [session — confirm]
- [ ] Volume below the hip works well; drop-waist / hip-level transitions are comfortable.
      [session — confirm whether "exclusively below the hip" or just "works well"]
- [x] No cropped tops that expose the midsection. [session — confirm]
- [x] Practical, comfortable shoes for walking-heavy days (flats, loafers, sneakers,
      structured boots, low block heels). Kitten heels and dressier shoes are valid when the
      day allows. [doc lookbook + session]
- [x] Maintenance burden matters: prefer low-maintenance dressing; flag pieces that need
      special handling rather than silently styling around them. [doc + AGENTS.md]

## Layer 2 — Proven Formulas (descriptive, NOT prescriptive)

> These represent what I currently know how to make work — a floor for when confidence
> matters, never the limit of what I like or want to try.

- [x] Core formula: fitted/structured top + relaxed/flowing bottom — OR bold print on one
      piece + solid on the other. [doc]
- [x] Dark fitted/structured top + wide-leg or flowing pants / midi-maxi skirt is the most
      reliable version of the above. [session — confirm]
- [ ] Minis work when the top creates clear hip-level definition (knot, tuck, hip-length
      hem). [session — confirm]
- [x] With leggings: dark tops, longer length, or a layered transition. [doc]
- [x] With wide-leg pants: fitted top ending at or just above the waistband. [doc]
- [x] Layering: open shirt or vest over a fitted base is almost always better than the top
      alone. [doc]
- [x] Pattern mixing works when prints SHARE A COLOR FAMILY and one is simpler than the
      other. (Full rule — prompts had dropped the color-family clause.) [doc]
- [x] Accessories: at least one finishing element elevates almost anything; [doc]
- [x] Light colors expand, dark colors recede — useful for proportion decisions. [doc]
- [x] Confirmed Outfit Lookbook = styling_session_context.md §Lookbook + saved/confirmed
      outfits in the app DB (the DB is the living, current version). [doc + app data]

## Layer 3 — Aesthetic Gravity (soft preferences — weighted, never walled)

- [x] Home base: "Urban Artisan" — intentional, relaxed, artisan-quality; linen, textured
      knits, quality cotton; utility details. A center of gravity, not a fence. [doc]
- [ ] Frequently worn base palette (descriptive, from wardrobe + lookbook): cream/oatmeal,
      black, navy/denim, olive, brown, grey. [doc + wardrobe data]
- [ ] Accent colors in active use: orange, teal, emerald, rust. [doc — confirm list]
- [x] Bold colors and prints are welcome; not afraid of pattern mixing. [doc]
- [x] REMOVED — "Plum is one of my best colors": model invention. Plum pieces exist and are
      worn; the superlative is not Yuna's. Do not state plum (or any color) as a favorite
      or "best color" anywhere. [Yuna 2026-06]
- [x] REMOVED — mustard as a favorite/signature color: model invention. The mustard
      corduroys are a liked garment; that is all. [Yuna 2026-06]
- [x] No other "favorite"/"best"/"signature color" claims may be added except by Yuna.

## Layer 4 — Style Lanes (an OPEN set, occasion- and mood-driven)

> I like all kinds of styles. My current outfits are the styles I know how to execute, not
> the boundary of my taste. The app's job is to expand my execution range across lanes —
> that is what Missions are for — never to gatekeep a lane as "not my style."

- [x] All lanes are valid when occasion and garment construction support them: bohemian,
      folk/artisan, romantic, utilitarian, polished, minimalist, preppy (e.g. Modern Preppy
      for a school event), playful, edgy, ... This list is open-ended. [Yuna 2026-06]
- [x] The quality bar is EXECUTION, not conformity: any lane done well passes.
- [x] What fails is drift — the bad version of a lane, traced to real feedback:
  - [x] catalog / mature-catalog drift [chips: "Catalog drift", "Catalog maturity drift"]
  - [x] teacher/librarian drift [chips: "Teacher/librarian drift"]
  - [ ] passive softness / too soft, soft+soft+soft with no grounding [chips: "Too soft"]
  - [ ] costume/festival stereotype (the cartoon version of boho/folk) [session — confirm]
  - [x] generic retail sameness [session — confirm]
- [x] REMOVED unless ratified — embellished drift vocabulary the models invented:
      "ultra-feminine department-store styling", "generic fashion-blogger layering",
      "beige/taupe mush", "boring tonal sludge", "librarian" as a standalone insult beyond
      the chip meaning. Keep any that genuinely resonate: ______________ [confirm or cut]
- [x] Body contract (Layer 1) applies inside every lane; nothing else from Layers 2–3
      restricts a lane.
